帮助中心

📍 从哪里开始？

先进入「课件生成」挑一个章节试试，满意后再到「互动课堂」「作业评测」补充课堂配套。

⚙️ 生成引擎说明

当前为本地模板引擎：按国家课程标准的结构与常见教学法，从内置素材库中组合生成，断网也能用。

在「设置」中填入大模型 API 后，将切换为 API 深度生成，回答更富个性化。

📐 几何引擎怎么用？

选择图形类型、形状与尺寸，引擎会给出 模型 → 渲染 → 验证 三段式结果：SVG 图形 + 边长/角度/性质断言，全部通过标记 ✓。

🧑‍🏫 AI 课堂是什么？

对标 OpenMAIC 的多角色课堂：AI 老师主讲、助教补充讲解、三类同学（学霸质疑 / 问题达人 / 小白提问）参与互动。学生可文字或语音答题，关键词即时批改打分；配合实时共享白板随讲随写，结束后生成课堂报告。

⚗️ 模拟实验能验证什么？

三款确定性仿真：平抛运动、弹簧振子、圆与 π（正多边形逼近）。动画由参数实时驱动，同时运行数值公式断言（如 t=√(2h/g)、T=2π√(m/k)），可点开逐条核对。

🧩 项目学习 PBL？

生成驱动性问题 → 项目背景 → 四个里程碑 → 任务卡 → 成果要求 → 评价量表，整套可打印，直接组织小组探究课。

🔊 语音与联网怎么用？

浏览器支持时用 Web Speech 语音讲课（TTS）与语音答题（STT），不支持自动降级为文字；联网搜索面板可内联展示摘要并在新标签打开原文。

📤 一键开课？

在「设置 > 一键开课渠道」配置飞书 / Slack Webhook 或 Telegram Bot（Token 或完整 sendMessage 链接），课堂进行中点击「一键开课」即可把课题与课堂链接推送到对应群。

「复制课堂链接」复制本页地址（带 #classroom），发给学生或同事，打开后会自动定位到课堂视图，无需额外安装。

📄 结果能做什么？

打印/导出为可打印页面；几何图形可单独下载 SVG，直接插入 Word 或课件。
