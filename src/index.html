详见下节：四段式生成机制
关键壁垒 · 为什么图形内容可靠

四段式几何内容生成引擎

数学、物理等学科对图形有确定性要求。我们不依赖"画得差不多"的生成，而是把教材图元转成可验证的结构化描述。

1

符号化建模

把教材中的图形与文字描述转成结构化 DSL：点、线、角、圆及约束关系，随版本入库管理。

示例：∠AOB = 90°，|AB| = 6，点 C 为 AB 中点
2

确定性渲染

几何约束求解器根据模型生成图形，同一输入永远得到同一输出，可复现、可回归、可单测。

确定性：同输入 → 同输出 → 可回归测试
3

验证器三件套

数量校验（图形规模）、关系校验（垂直/平行/相等）、标签校验（标注与题意一致），任一失败即拒绝输出。

未通过验证的图形不进入课件
4

导出与交付

生成可交互课堂组件：尺规演示、角度标注、动态探究，与课件结构绑定，供教师一键嵌入。

输出：课件组件 / 可编辑图形 / 演示动画
验证证据面板 · 概念示意

✓数量：点 3 · 线段 3 · 标注 1
✓关系：AB = AC · ∠A 顶角
✓标签：ABC 顶点标识一致

确定性约束：数列、函数图像、单位换算等场景复用同一机制（规划中）
